<Tabs>
  <Tab title="One-line install (Linux)">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/agentlinkprotocol/grid/main/deploy/install.sh | sh
    ```
    The script downloads the latest release for your CPU, verifies its checksum, installs `grid` into
    `/usr/local/bin`, creates the `grid` system user, initialises `/var/lib/grid` (config, node key, API token),
    installs and starts the `grid` systemd service. Variables: `GRID_BOOTSTRAP=<multiaddr,…>`,
    `GRID_OBSERVER=1`, `GRID_CAPACITY_GIB=50`, `GRID_VERSION=v0.1.0`.

    ```bash
    sudo journalctl -u grid -f                              # logs
    sudo grid status --config /var/lib/grid/grid.toml       # status (JSON)
    sudo cat /var/lib/grid/api.token                        # local API token
    ```
  </Tab>
  <Tab title="Docker">
    ```bash
    docker run -d --name grid --restart unless-stopped \
      -p 4001:4001/udp -p 4001:4001 -p 127.0.0.1:7777:7777 -v grid-data:/data \
      -e GRID_BOOTSTRAP=/dns4/boot.example.org/tcp/4001/p2p/12D3Koo... \
      ghcr.io/agentlinkprotocol/grid:latest
    docker exec grid cat /data/api.token
    ```
    Or `deploy/docker-compose.yml` from the repository. The API is bound to localhost on the host; the data
    volume holds the key, token and database.
  </Tab>
  <Tab title="From source">
    ```bash
    git clone https://github.com/agentlinkprotocol/grid && cd grid
    cargo build --release
    ./target/release/grid init          # ~/.grid/grid.toml, keys, API token
    ./target/release/grid run
    ```
    Set `network.bootstrap` in `~/.grid/grid.toml` if the built-in list is empty (see
    [Bootstrap nodes](/node/bootstrap)).
  </Tab>
</Tabs>

The node solves its identity proof of work (a few seconds at 20 bits), loads the map, joins the network and
serves the local API on `127.0.0.1:7777`.

## Development mode

```bash
grid init --dev --observer
grid run
```

`--dev` runs an **offline single-node Atlas**: no libp2p, quota disabled, 8-bit proof of work, a 256-zone development
map built from a synthetic corpus, and the deterministic *lexical* development embedder (`alp-embed-dev`). It is
enough to develop an agent end to end. Semantic paraphrase ("developer who loves astronomy" finding "Software
developer") needs the real model: build with `--features onnx` and set `node.embedder = "onnx"`.

## Ports and firewall

| Port | Protocol | Purpose |
| --- | --- | --- |
| 4001/udp | QUIC | libp2p (preferred) |
| 4001/tcp | TCP | libp2p (fallback) |
| 7777/tcp | HTTP | local API, bind to `127.0.0.1` only |

Nodes behind NAT use hole punching and relays; a public address makes you a better guardian.

## Useful commands

```bash
grid token                 # print the API bearer token
grid status                # status of the running node (JSON)
grid search "math teacher" # search through the running node
grid openapi > openapi.json
grid keygen                # a fresh Ed25519 seed for an agent
```
