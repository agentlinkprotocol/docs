# Agent Link Protocol documentation

Mintlify site: concepts, how to run a node, the Atlas v1 specification, the Grid local API reference (generated
`openapi.json`) and the SDK guides.

```bash
npm i -g mintlify
mintlify dev
```

`api/openapi.json` is copied from `grid/openapi.json` (`grid openapi`). Apache-2.0.

## Branches and releases

Work on `develop`, open a pull request to `main` (`ci` runs on the pull request only: navigation pages exist, no broken links, OpenAPI parses).
Mintlify deploys `main` by itself once its GitHub app is installed on the repository.
